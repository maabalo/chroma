      # readme

      What is Chroma?

      Chroma makes color palettes for websites, apps, slides or any design. Generate colors that work together, keep the ones you like, fine-tune them, check their contrast, and copy them as code. Everything runs in your browser.

      01 Quick start

      1. Press Space or generate for a new palette.
      2. Choose a mode to control how the colors relate. auto picks a different one each time.
      3. Click the lock on a color you like. Locked colors don't change, and new palettes are built around the first locked color.
      4. Click the pipette to choose a color yourself. A color you choose is locked automatically.
      5. Click a color code (HEX, RGB or HSL) to copy it.
      6. Use save, saved palettes and export to keep your palette and use it.

      02 Reading a color

      HEX · RGB · HSL
      The same color written in three common formats.
      / number
      Contrast ratio between this color and white or black text. Higher is easier to read.
      AAA · AA
      7 or more is AAA; 4.5 or more is AA. Both pass the accessibility guidelines (WCAG) for normal text.
      AA large · fail
      3 or more passes only for large text (24px, or 19px bold). Below 3 fails.

      03 Modes

      analogous
      Neighbouring hues. Calm and natural.
      monochrome
      One hue from light to dark. Clean and safe.
      complementary
      Two opposite hues. Strong contrast.
      split complementary
      One hue plus the two on each side of its opposite. Lively but balanced.
      triadic
      Three evenly spaced hues. Bright and playful.
      random
      No rules. Good for surprises.

      05 Saving & sharing

      • Saved palettes are kept in this browser only (up to 60). Clearing your browser data removes them.
      • The address bar always contains the current colors. Bookmark it, or use copy share link, to come back to the palette later.
      • Export gives CSS variables, SCSS, a Tailwind config, JSON or a plain HEX list. Copy it or download it as a file.
      • Nothing is uploaded. Chroma works offline once the page has loaded.
